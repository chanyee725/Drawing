# 6. 앱 셸: 프로젝트 중심 구조와 Linear에 가까운 다크 화면 (E42, #122)

상태: **안 확정(2026-11-13).** 대시보드·프로젝트 홈·사이드바는 B안, 문서·다이어그램 화면은 A안이에요(§3.1). 색은 shadcn/ui 기본 테마, 글꼴은 Pretendard, 크기는 첫 시안의 약 108%예요(§4). 구현은 §9의 티켓 5개로 나눠요. 이 문서는 설계만이고 앱 코드는 바꾸지 않았어요.

- 프로토타입: `6-app-shell-prototype/index.html` (정적 HTML, 네트워크 요청 없음)
  - 주소 뒤에 `?layout=a|b|mix&theme=dark|light&screen=home|project|doc|cmd|nav` (`mix` = 확정 조합)
  - 스크린샷: `[LAYOUTS="a b mix"] [THEMES="dark light"] 6-app-shell-prototype/shoot.sh <출력 폴더> [PretendardVariable.woff2]` (헤드리스 Chrome, 보이는 창 없음)
- 근거: 이슈 #122 본문과 2026-11-13 사용자 코멘트(Eraser 대시보드식 구조 + Linear풍 모습, 이어서 shadcn 기본 테마·Pretendard·108%, 안 선택)

## 0. 결정과 바뀌는 규칙

1. **앱 화면은 shadcn/ui로.** 색은 shadcn/ui 기본 테마(기본색 neutral, 라이트·다크 기본 토큰) 그대로이고, 그 위에 따로 만든 회색은 없어요.
   구현 때 앱 화면 전체를 shadcn/ui 컴포넌트로 바꾸고, 손으로 만든 컨트롤과 inline style `var(--…)`는 남기지 않아요.
   배치·밀도·사이드바·목록 모양은 Linear식 구조를 따르지만 Linear의 이름, 로고, 아이콘·일러스트·폰트 파일, CSS, 코드, 색 값은 쓰지 않아요.
   (앞선 "Linear 다크에 매우 가깝게 색을 맞춘다"와 측정 색표 `#141516` 등은 버렸어요.)
2. **캔버스와 다이어그램 블록은 Eraser 규칙 그대로**(문서 5 §5).
3. **구조는 프로젝트가 먼저.** 프로젝트 A를 열면 A의 홈이 나오고, 하위 문서(예: 로그인 로직, 데이터 수집 로직)가 중첩 목록으로 보여요. 단순 파일 트리는 목표가 아니에요.
4. **넣지 않는 것:** 로그인, 계정, 아바타, 초대, 공유, 댓글, 업그레이드·체험 카드, 봇·AI 채팅. 개인용 로컬 도구예요.

## 1. 데이터 모델 (기본값)

| 개념 | 디스크 | 비고 |
|---|---|---|
| 작업 공간 | 서버가 연 폴더 | 이름 = 폴더 이름 |
| 프로젝트 | 작업 공간의 **최상위 폴더** | 메타는 선택: `<project>/.project.json` = `{ "name", "icon", "description" }` |

| 미분류 | 작업 공간 루트에 바로 있는 파일 | "미분류" 필터와 그룹 |

- 파일 형식은 바꾸지 않아요. 새로 생기는 건 선택 메타 파일 하나예요(없으면 폴더 이름, 첫 글자 아이콘, 설명 없음).
- 하위 문서 규칙("같은 이름 폴더")은 지금 트리 API(`TreeNode`)로 바로 계산돼요. 폴더만 있고 같은 이름 파일이 없으면 "묶음"(문서 없는 부모)으로 보여요.
- 문서 종류 아이콘(문서·캔버스·파이프라인 계획)은 파일이 처음 열리는 보기로 정해요. 모든 파일은 여전히 문서 + 캔버스를 함께 가져요.
- 메타에는 개인정보를 넣지 않아요(만든 사람 칸 없음).

## 2. 화면 구성 (공통)

### 2.1 왼쪽 사이드바 (위에서 아래로)

1. 작업 공간 이름 (계정 메뉴·팀 전환·초대 없음), 찾기 버튼 `Ctrl K`
2. 보기: **모든 파일** `A`, **최근** `R`, **보관함** `B` (한 글자 단축키, 입력 칸 밖에서만)
3. **프로젝트** 섹션 + 버튼. 프로젝트를 펼치면 하위 문서가 중첩돼 보여요. 닫힌 부모는 하위 개수를 보여요.
4. **모델 연결**: Claude·Codex·Gemini(agy) 각각 연결됨/연결 안 됨, 사용 한도(5시간 창 %). 누르면 연결 흐름이 열려요. 75%를 넘으면 경고색.
5. 설정 `,`
6. **새 파일** 기본 버튼 `N` (A안만 맨 아래. B안은 맨 위 아이콘)

### 2.2 메인 (대시보드 = "모든 파일")

- 필터 탭: 전체, 최근, 프로젝트별, 미분류
- 찾기 칸 `/`, 명령 메뉴 `Ctrl K` 안내
- 빠른 만들기: 새 문서 `D`, 새 캔버스 `C`, 새 파이프라인 계획 `P`, 템플릿에서 만들기 `T`
- 파일 표: 이름, 위치(프로젝트 / 상위 문서), 만든 때, 고친 때(기본 정렬), ⋯ 메뉴. 줄을 누르면 파일이 열려요.

### 2.3 프로젝트 홈

- 머리: 아이콘, 이름, 설명(있을 때), 문서 수 · 실행 중 파이프라인 · 폴더 경로
- 이 프로젝트 안에 만들기, 탭(문서·최근·파이프라인), 이 프로젝트에서 찾기
- 하위 문서 **중첩 목록**: 펼치기 단추(`aria-expanded`), 들여쓰기 22px, 하위 개수, 만든 때·고친 때

### 2.4 문서 화면

- 위 막대: 경로(프로젝트 / 상위 문서 / 문서), 저장 상태 점, 보기 전환 [문서 | 둘 다 | 캔버스], 내보내기, ⋯
- 문서 본문 끝에 **하위 문서** 블록(목록 + "하위 문서 추가"). 사이드바와 같은 데이터예요.
- 390px에서는 캔버스를 숨기고 [문서 | 캔버스] 둘 중 하나만 보여요.

### 2.5 명령 메뉴 `Ctrl K`

- 600px, 화면 위 14% 지점. 입력 칸 오른쪽에 지금 프로젝트 칩(범위). 
- 묶음: 문서, 프로젝트(이동 `G P`), 동작(새 문서, 새 파이프라인 계획, 모델 연결, 테마)
- 아래 안내: ↑↓ 이동, ↵ 열기, esc 닫기. 390px에서는 위에 붙고 안내 줄은 숨겨요.

### 3.2 비교 (선택 전 기록)

| | **A안: 대시보드형** (코멘트 구조 그대로) | **B안: Linear식 변형** |

(표의 px 값은 첫 시안 기준이에요. 108%로 키운 값은 §4.2.)

## 4. 토큰 (프로토타입 값)

### 4.1 색: shadcn/ui 기본 테마 (neutral)

`npx shadcn init`이 기본색 neutral로 만드는 값 그대로예요(`--radius: 0.625rem`). 프로토타입의 역할 이름(`--frame`, `--text-3` 등)은
이 토큰을 가리키는 별칭일 뿐이에요. 구현 때는 shadcn 이름만 써요. 문서 5 §3.1의 색 초안(hue 280 회색, 보라 `--brand`)은 이 표가 대체해요.

| shadcn 토큰 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| `--background` / `--foreground` | `oklch(1 0 0)` / `oklch(0.145 0 0)` | `oklch(0.145 0 0)` / `oklch(0.985 0 0)` | 메인 판, 본문 글자 |
| `--sidebar` / `--sidebar-foreground` | `oklch(0.985 0 0)` / `oklch(0.145 0 0)` | `oklch(0.205 0 0)` / `oklch(0.985 0 0)` | 사이드바, 판 바깥 바탕 |
| `--sidebar-accent` / `--sidebar-border` | `oklch(0.97 0 0)` / `oklch(0.922 0 0)` | `oklch(0.269 0 0)` / `oklch(1 0 0 / 10%)` | 사이드바 hover·현재 줄 / 판 테두리 |
| `--sidebar-primary` | `oklch(0.205 0 0)` | `oklch(0.488 0.243 264.376)` | 작업 공간 표시 |
| `--card` / `--popover` | `oklch(1 0 0)` | `oklch(0.205 0 0)` | 카드, 메뉴, 명령 메뉴 |
| `--muted` / `--accent` / `--secondary` | `oklch(0.97 0 0)` | `oklch(0.269 0 0)` | 프로젝트 표시, 선택 줄 / hover / 보조 단추 |

- shadcn에 없는 **상태색** `--ok`, `--warn`만 Dispatch 값을 그대로 둬요(문서 5 §3.1). 색은 상태(모델 연결 점, 사용량 경고, "실행 중", 저장 점)에만 써요.
- 프로젝트 표시는 색 없이 `--muted` 바탕 + 첫 글자예요(첫 시안의 프로젝트별 색은 뺐어요).
- 반지름: shadcn 단계 그대로 `sm 6px`(kbd, 표시), `md 8px`(줄, 단추, 탭, 입력), `lg 10px`(명령 메뉴, 도구 막대), `xl 14px`(떠 있는 판, 카드).
- 그림자: 메뉴·명령 메뉴 `shadow-md` + 1px `--border`, 대화상자 바탕 `black/50`.
