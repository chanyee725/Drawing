# 6. 앱 셸: 프로젝트 중심 구조와 Linear에 가까운 다크 화면 (E42, #122)

상태: 시안(설계만, 앱 코드는 바꾸지 않았어요). 사용자가 A안·B안 중 하나를 고르면 구현 티켓으로 나눠요(§9).

- 프로토타입: `6-app-shell-prototype/index.html` (정적 HTML, 네트워크 요청 없음)
  - 주소 뒤에 `?layout=a|b&theme=dark|light&screen=home|project|doc|cmd|nav`
  - 스크린샷: `6-app-shell-prototype/shoot.sh <출력 폴더> [Inter.woff2] [Pretendard.woff2]` (헤드리스 Chrome, 보이는 창 없음)
- 근거: 이슈 #122 본문과 2026-11-13 사용자 코멘트(Eraser 대시보드식 구조 + Linear풍 모습)

## 0. 결정과 바뀌는 규칙

1. **앱 화면(크롬)은 Linear 다크 UI에 매우 가깝게.** 표면 단계, 회색 단계, 1px 테두리, 밀도, 글자 크기, 사이드바·목록 배치를 관찰로 맞춰요.
   문서 5의 "특성만, 정확한 색 금지"(§2, §7)는 **앱 화면에 한해** 이 결정으로 바뀌어요.
   그대로 남는 금지: Linear의 이름, 로고, 아이콘·일러스트·폰트 파일, CSS, 코드. 값은 우리가 oklch로 새로 정하고 스크린샷으로 맞춰요.
2. **캔버스와 다이어그램 블록은 Eraser 규칙 그대로**(문서 5 §5).
3. **구조는 프로젝트가 먼저.** 프로젝트 A를 열면 A의 홈이 나오고, 하위 문서(예: 로그인 로직, 데이터 수집 로직)가 중첩 목록으로 보여요. 단순 파일 트리는 목표가 아니에요.
4. **넣지 않는 것:** 로그인, 계정, 아바타, 초대, 공유, 댓글, 업그레이드·체험 카드, 봇·AI 채팅. 개인용 로컬 도구예요.

## 1. 데이터 모델 (기본값)

| 개념 | 디스크 | 비고 |
|---|---|---|
| 작업 공간 | 서버가 연 폴더 | 이름 = 폴더 이름 |
| 프로젝트 | 작업 공간의 **최상위 폴더** | 메타는 선택: `<project>/.project.json` = `{ "name", "icon", "description" }` |
| 문서 | 프로젝트 안의 파일 | 지금 파일 형식 그대로 |
| 하위 문서 | 문서 `X`와 같은 이름의 폴더 `X/` 안 파일 | `로그인 로직.dpx.json` + `로그인 로직/토큰 갱신.dpx.json` |
| 미분류 | 작업 공간 루트에 바로 있는 파일 | "미분류" 필터와 그룹 |
| 보관함 | 지금 휴지통 | 이름만 "보관함"으로 |

- 파일 형식은 바꾸지 않아요. 새로 생기는 건 선택 메타 파일 하나예요(없으면 폴더 이름, 첫 글자 아이콘, 설명 없음).
- 하위 문서 규칙("같은 이름 폴더")은 지금 트리 API(`TreeNode`)로 바로 계산돼요. 폴더만 있고 같은 이름 파일이 없으면 "묶음"(문서 없는 부모)으로 보여요.
- 문서 종류 아이콘(문서·캔버스·파이프라인 계획)은 파일이 처음 열리는 보기로 정해요. 모든 파일은 여전히 문서 + 캔버스를 함께 가져요.
- 메타에는 개인정보를 넣지 않아요(만든 사람 칸 없음).

## 2. 화면 구성 (공통)

### 2.1 왼쪽 사이드바 (위에서 아래로)

1. 작업 공간 이름 (계정 메뉴·팀 전환·초대 없음), 찾기 버튼 `Ctrl K`
2. 보기: **모든 파일** `A`, **최근** `R`, **보관함** `B` (한 글자 단축키, 입력 칸 밖에서만)
3. **프로젝트** 섹션 + 버튼. 프로젝트를 펼치면 하위 문서가 중첩돼 보여요. 닫힌 부모는 하위 개수를 보여요.
4. **모델 연결**: Claude·Codex·Gemini(agy) 각각 연결됨/연결 안 됨, 사용 한도(5시간 창 %). 누르면 연결 흐름이 열려요. 75%를 넘으면 경고색.
5. 설정 `,`
6. **새 파일** 기본 버튼 `N` (A안만 맨 아래. B안은 맨 위 아이콘)

### 2.2 메인 (대시보드 = "모든 파일")

- 필터 탭: 전체, 최근, 프로젝트별, 미분류
- 찾기 칸 `/`, 명령 메뉴 `Ctrl K` 안내
- 빠른 만들기: 새 문서 `D`, 새 캔버스 `C`, 새 파이프라인 계획 `P`, 템플릿에서 만들기 `T`
- 파일 표: 이름, 위치(프로젝트 / 상위 문서), 만든 때, 고친 때(기본 정렬), ⋯ 메뉴. 줄을 누르면 파일이 열려요.

### 2.3 프로젝트 홈

- 머리: 아이콘, 이름, 설명(있을 때), 문서 수 · 실행 중 파이프라인 · 폴더 경로
- 이 프로젝트 안에 만들기, 탭(문서·최근·파이프라인), 이 프로젝트에서 찾기
- 하위 문서 **중첩 목록**: 펼치기 단추(`aria-expanded`), 들여쓰기 22px, 하위 개수, 만든 때·고친 때

### 2.4 문서 화면

- 위 막대: 경로(프로젝트 / 상위 문서 / 문서), 저장 상태 점, 보기 전환 [문서 | 둘 다 | 캔버스], 내보내기, ⋯
- 문서 본문 끝에 **하위 문서** 블록(목록 + "하위 문서 추가"). 사이드바와 같은 데이터예요.
- 390px에서는 캔버스를 숨기고 [문서 | 캔버스] 둘 중 하나만 보여요.

### 2.5 명령 메뉴 `Ctrl K`

- 600px, 화면 위 14% 지점. 입력 칸 오른쪽에 지금 프로젝트 칩(범위). 
- 묶음: 문서, 프로젝트(이동 `G P`), 동작(새 문서, 새 파이프라인 계획, 모델 연결, 테마)
- 아래 안내: ↑↓ 이동, ↵ 열기, esc 닫기. 390px에서는 위에 붙고 안내 줄은 숨겨요.

## 3. 두 레이아웃 안

| | **A안: 대시보드형** (코멘트 구조 그대로) | **B안: Linear식 변형** |
|---|---|---|
| 메인 틀 | 사이드바 옆에 붙은 판, 왼쪽 1px 선 | 바탕 위에 떠 있는 판(8px 여백, 8px 모서리, 1px 테두리) |
| 머리 | 48px, 제목 + 명령 안내 | 44px, 제목 옆에 알약 탭, 오른쪽 정렬·찾기 단추 |
| 빠른 만들기 | 카드 4장(설명 + 단축키) | 머리 아래 얇은 점선 칩 한 줄 |
| 파일 목록 | 표(위치 열 있음), 가운데 1100px | 프로젝트별 묶음 목록, 전체 폭, 38px 줄 |
| 프로젝트 홈 | 카드 + 중첩 표(하위 문서 수 열) | 머리 탭(문서·파이프라인·개요) + `새 문서` 단추 + 중첩 목록 |
| 모델 연결 | 모델마다 한 줄 + 사용량 막대 | 점 + % 한 줄 요약(누르면 자세히) |
| 새 파일 | 사이드바 맨 아래 큰 버튼 | 작업 공간 이름 옆 아이콘 |
| 좋은 점 | 처음 보는 사람도 바로 만들기 쉬움, 한도가 잘 보임 | 더 촘촘해 파일이 많아도 한눈에, Linear에 더 가까움 |
| 아쉬운 점 | 카드가 화면 위쪽을 차지 | 만들기 단추가 덜 눈에 띔, 한도가 작게 보임 |

추천: **B안의 틀(떠 있는 판, 44px 머리, 묶음 목록) + A안의 모델 연결 블록과 맨 아래 새 파일 버튼.** 결정은 사용자에게 맡겨요(§10).

## 5. 접근성 확인

명암비(배경 대비, 계산값):

| 글자 | 다크 `--main` | 다크 `--frame` | 라이트 `--main` | 라이트 `--frame` |
|---|---|---|---|---|
| text-1 | 16.4 | 17.1 | 17.7 | 16.5 |
| text-2 | 10.0 | 10.4 | 10.4 | 9.7 |
| text-3 (메타) | 6.0 | 6.3 | 6.0 | 5.6 |
| text-4 (비활성만) | 3.4 | 3.5 | 3.1 | 2.9 |
| brand | 6.2 | 6.5 | 5.9 | 5.5 |
| 흰 글자 / brand-btn | 4.8 | | | |

- 의미 있는 글자(위치, 개수, 미분류)는 text-3 이상. text-4는 비활성·자리 표시에만 써요.
- 포커스: 모든 단추·탭·줄에 2px `--brand` 링(`:focus-visible`). 링을 지우지 않아요.
- 키보드: 사이드바 보기 `A R B`, 새 파일 `N`, 찾기 `/`, 명령 `Ctrl K`, 빠른 만들기 `D C P T`. 입력 칸에 포커스가 있으면 한 글자 단축키는 꺼져요.
- 의미: 사이드바 `nav` + `aria-current="page"`, 펼치기 `aria-expanded`, 필터 `role="tablist"`, 보기 전환 `aria-pressed`, 명령 메뉴 `role="dialog" aria-modal` + `listbox`, 아이콘 단추는 모두 `aria-label`.
- 모델 상태는 색만으로 말하지 않아요(“연결됨/연결 안 됨”, % 글자를 같이).
- 390px 터치 대상은 40px 이상(위 막대 단추, 서랍 줄 36px → 구현 때 44px로 올려요).

## 6. 390px (모바일 폭)

- 사이드바는 서랍(☰)으로, 위 막대 48px에 제목·찾기·새 파일.
