# T7 제안: sim-studio `docs/handover/README.md` 한 줄 안내

이 문서는 제안문만 담아요. sim-studio 저장소는 수정하지 않았어요. 넣을지, 어디에 넣을지는 사용자가 정해요.

## 제안 문장

```
> 실시간으로 보려면 `npm install && npm run build && npm start -- <이 폴더 경로>` 를 Draw-Pipelines 저장소에서 실행하고, 출력된 주소(기본 `http://127.0.0.1:4330/`)를 열어요.
```

## 메모

- `<이 폴더 경로>` 는 실제 경로로 바꿔 넣어요. 예: `docs/handover` 의 절대 경로.
- 한 줄로 두려면 `npm run build` 를 빼고 README 링크만 걸 수도 있어요. 다만 빌드 없이는 페이지가 열리지 않아요.
